# trendyol-cosmetics-sentiment-analysis
Sentiment analysis and root cause analysis of customer reviews in the cosmetics category on Trendyol
# Dataset Documentation

## Dataset Overview

This research uses customer reviews collected from the cosmetics category of Trendyol.

The dataset was used to investigate customer satisfaction and recurring product complaints through sentiment analysis and text mining.

## Dataset Scope

The study includes four product categories:

- Lipstick
- Mascara
- Foundation
- Sunscreen

**Total number of reviews analyzed:** 60,873

## Dataset Attributes

The collected data included the following fields:

| Field | Description |
|---|---|
| User information | User-related information |
| Created date | Review creation date |
| Rating | Product rating |
| Comment | Customer review text |

## Data Processing

The collected reviews were processed using Python.

The analysis included:

- Turkish text cleaning
- Text preprocessing
- Sentiment classification
- Category-based comparison
- Negative review analysis

## Privacy and Data Sharing

The original CSV and Excel datasets are intentionally not included in this public repository.

Potentially identifiable user information and original customer review records are not publicly shared.

This documentation provides an overview of the dataset and its role in the research without exposing the original records.

## Reproducibility

The analysis notebooks and aggregated research results may be shared separately, provided they do not expose personal information or restricted source data.

**Note:** Access to the original datasets is not provided through this repository.
